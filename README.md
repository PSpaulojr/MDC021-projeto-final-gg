# Classificação de Emoções em Comentários (GoEmotions)

Trabalho final do curso de Machine Learning.

O objetivo é classificar as emoções expressas em comentários do Reddit usando o dataset
[GoEmotions](https://huggingface.co/datasets/google-research-datasets/go_emotions), do Hugging Face.
É um problema de classificação **multi-label** (um comentário pode ter mais de uma emoção) e
com classes desbalanceadas.
